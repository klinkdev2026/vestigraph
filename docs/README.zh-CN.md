# Vestigraph 公开文档

Vestigraph 保存本地文件和 KLayout 历史。完整安装在同一 Python 环境中使用兼容 Klink，让 KLayout 记录已保存版图，并让现有 Klink MCP server 发现 Vestigraph 工具。

| 导出旧版本并了解数据位置 | [恢复](RECOVERY.zh-CN.md) |
| 使用命令行 | [命令行](CLI.zh-CN.md) |
